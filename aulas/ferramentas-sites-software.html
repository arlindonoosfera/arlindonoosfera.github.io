0. Genética

FerramentaPara que serveTipo

O BLAST é especialmente importante: compara sequências de nucleotídeos ou proteínas com bancos de sequências e permite investigar similaridade, relações evolutivas e famílias gênicas. (BLAST)

O Ensembl é excelente para passar de “tenho uma sequência/gene” para “onde isso está no genoma, quais são os transcritos, variantes etc.”. A versão atual também está expandindo a cobertura para muitos organismos além dos modelos tradicionais. (Ensembl)

dados reais de biodiversidade + estatística + GIS.

🌎 Bancos e plataformas

  • GBIF — ocorrências de espécies, distribuição geográfica e dados de biodiversidade.
  • iNaturalist — observações e identificação de organismos.
  • OBIS — biodiversidade marinha.
  • eBird — excelente para ecologia de aves.
  • Movebank — movimentação e rastreamento de animais.
  • NASA Earthdata — dados ambientais, clima, vegetação, sensoriamento remoto.

O GBIF é particularmente importante: fornece acesso aberto a grandes conjuntos de dados de biodiversidade e possui ferramentas/API para consultar registros de ocorrência. (GBIF)

📊 Para analisar

  • R Project
  • RStudio / Posit
  • QGIS
  • ArcGIS

R + QGIS + GBIF é uma combinação extremamente boa para ecologia.

2. Microbiologia

🦠 Bancos e identificação

  • BacDive — informações fenotípicas, taxonômicas e genômicas de bactérias.
  • NCBI Pathogen Detection — genomas de patógenos e vigilância genômica.
  • NCBI BLAST — identificação/comparação de sequências.
  • SILVA — rRNA e taxonomia microbiana.
  • RDP — classificação de sequências de rRNA.
  • MGnify — metagenômica.

🧬 Para microbiologia moderna

Vale aprender:

16S rRNA → BLAST → classificação taxonômica → filogenia → metagenômica.

E, posteriormente:

QIIME 2 → microbioma → diversidade α/β → composição microbiana.

3. Virologia

Aqui há um conjunto muito bom de ferramentas específicas.

  • NCBI Virus — sequências virais e metadados.
  • ICTV — taxonomia oficial dos vírus.
  • Nextstrain — evolução e epidemiologia genômica de vírus.
  • GISAID — compartilhamento de dados genômicos, especialmente importante para influenza e coronavírus.
  • NCBI BLAST — comparação de genomas/proteínas virais.

O NCBI Virus permite buscar, filtrar, visualizar e baixar sequências virais, inclusive utilizando metadados e painéis de acompanhamento de sequências de surtos. (NCBI)

E o ICTV deve entrar obrigatoriamente na sua lista: é a referência oficial para taxonomia viral; a versão atual disponibiliza a Master Species List e o navegador taxonômico. (ICTV)

4. Bioquímica / metabolismo

Aqui eu montaria uma “tríade”:

🧪 Reações e metabolismo

  • KEGG — vias metabólicas, genes e sistemas biológicos.
  • MetaCyc — vias metabólicas.
  • BRENDA — enzimas, propriedades e cinética.
  • Rhea — reações bioquímicas.
  • UniProt — proteínas e funções.
  • PDB — estruturas 3D de proteínas e outras macromoléculas.

🧬 Estrutura molecular

  • RCSB Protein Data Bank
  • AlphaFold Protein Structure Database
  • PyMOL
  • UCSF ChimeraX

Para entender metabolismo de verdade, eu colocaria KEGG + MetaCyc + BRENDA + Rhea no núcleo.

5. Evolução como eixo estruturante

Aqui muda um pouco: evolução não deveria ser apenas mais uma matéria. Ela pode conectar praticamente todas as outras.

🧬 Ferramentas

  • MEGA — alinhamento, distância genética e filogenia.
  • IQ-TREE — filogenia por máxima verossimilhança.
  • BEAST 2 — filogenia bayesiana e análises temporais.
  • HyPhy — seleção natural e evolução molecular.
  • PAML — evolução molecular.
  • BLAST — homologia.
  • Open Tree of Life — árvore da vida.

O IQ-TREE, por exemplo, atualmente está na versão 3.1.3 e oferece tanto software local quanto serviços web para análises filogenéticas. (IQ-TREE)

🌳 Para visualizar

iTOL — Interactive Tree of Life

É uma das ferramentas que eu mais recomendo aprender.

6. Biotecnologia

Aqui eu separaria bioinformática de desenho molecular/laboratorial.

🧬 DNA / plasmídeos / clonagem

  • Benchling
  • SnapGene
  • Addgene
  • NEBcutter
  • NCBI Primer-BLAST

🧪 Para engenharia genética

Depois entrariam:

  • desenho de primers;
  • restrição/ligação;
  • plasmídeos;
  • PCR;
  • CRISPR;
  • expressão gênica;
  • proteínas recombinantes;
  • análise de sequências;
  • desenho de construções.

Benchling + SnapGene + NCBI + Addgene já formam uma excelente base digital.

📈 Análise

Para aprender epidemiologia moderna, eu priorizaria R + Python + dados públicos + estatística.

9. Fungos 🍄

Aqui dá para fazer uma coleção muito boa.

  • MycoBank
  • Index Fungorum
  • Species Fungorum
  • UNITE
  • GBIF
  • iNaturalist
  • NCBI

O Index Fungorum é especialmente útil para nomenclatura: mantém dados dos nomes científicos de fungos e grupos relacionados, enquanto o próprio site direciona a informação taxonômica para o Species Fungorum. (Index Fungorum)

Para micologia molecular, eu acrescentaria:

UNITE → ITS → BLAST → filogenia → iTOL.
