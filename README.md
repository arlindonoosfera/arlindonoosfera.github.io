# arlindonoosfera.github.io

Portfólio e arquivo intelectual de Arlindo Noosfera. Site estático (HTML, CSS e JavaScript puro), compatível com GitHub Pages, sem build nem dependências.

## Como adicionar conteúdo
Edite apenas `data.js`:
- novo projeto: acrescente um objeto em `projetos` (estágios: proposta, planejamento, desenvolvimento, confirmar);
- link de plataforma: preencha `url` em `conexoes`;
- interesses e trajetória: edite `interesses` e `trajetoria`.

## Regras do projeto
Nada de dados, links, créditos ou resultados inventados. Estágio de cada item deve refletir o estado real.
