# arlindonoosfera.github.io

Portfólio e arquivo intelectual de Arlindo Noosfera. Site estático (HTML, CSS e JavaScript puro), compatível com GitHub Pages, sem dependências no navegador.

## Como adicionar conteúdo
- **Projetos, trajetória, interesses e links:** edite `data.js`.
- **Páginas de aula:** coloque arquivos `.md` em `conteudo/aulas/` e rode `python3 build.py`. Ele gera `aulas.html` e as páginas em `aulas/`. Exportações do Notion ("Markdown & CSV") funcionam. Cabeçalho opcional no topo do arquivo: `titulo`, `ano`, `estagio` (proposta, planejamento, desenvolvimento, aplicado).
- Depois de rodar `build.py`, faça commit dos arquivos gerados.

## Regras do projeto
Nada de dados, links, créditos ou resultados inventados. O estágio de cada item deve refletir o estado real. Não publicar códigos de turma, dados de estudantes nem links privados.
